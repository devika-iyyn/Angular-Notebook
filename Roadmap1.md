# Angular & Vue.js – 60-Day Learning Roadmap 1

## Phase 1: Angular Fundamentals (Days 1–15)

### Technical Concepts

1. Introduction to Angular and its architecture
2. Angular CLI and project setup
3. Angular project structure and configuration
4. Standalone components and component architecture
5. Templates and data binding
6. Property binding, event binding and two-way binding
7. Parent-child component communication
8. Input and Output properties
9. Built-in control flow (`@if`, `@for`, `@switch`)
10. Directives and pipes
11. TypeScript fundamentals in Angular

## Phase 2: Angular Advanced Concepts and Project Development (Days 16–30)

### Technical Concepts

1. Angular Router and navigation
2. Route parameters and nested routes
3. Route guards
4. Services and Dependency Injection
5. HTTP Client and REST API integration
6. Observables and RxJS fundamentals
7. Reactive Forms and Template-driven Forms
8. FormGroup, FormControl and FormArray
9. Form validation and error handling
10. Angular Signals and computed values
11. HTTP interceptors
12. Loading and error state handling
13. Basic component and service testing

## Phase 3: Vue.js Fundamentals (Days 31–45)

### Technical Concepts

1. Introduction to Vue.js and its architecture
2. Vue project setup using create-vue
3. Vue project structure
4. Single File Components
5. Template syntax and data binding
6. Event handling
7. Conditional rendering (`v-if`, `v-show`)
8. List rendering (`v-for`)
9. Reactivity using `ref()` and `reactive()`
10. Computed properties and watchers
11. Props and component events
12. Component lifecycle hooks
13. TypeScript integration with Vue

## Phase 4: Vue.js Advanced Concepts and Project Development (Days 46–60)

### Technical Concepts

1. Vue Router and navigation
2. Dynamic and nested routes
3. Navigation guards
4. REST API integration
5. Axios and asynchronous operations
6. API error handling
7. Pinia state management
8. Stores, state, getters and actions
9. Form handling and validation
10. Reusable composables
11. TypeScript with Vue
12. Component testing and debugging

---

## Learning Duration and Focus

| Phase | Duration | Framework |
|---|---|---|
| Phase 1 | 15 Days | Angular Fundamentals |
| Phase 2 | 15 Days | Angular Advanced Concepts |
| Phase 3 | 15 Days | Vue.js Fundamentals |
| Phase 4 | 15 Days | Vue.js Advanced Concepts |

**Total Duration:** 60 Days

**Technologies:** Angular, Vue.js, TypeScript, HTML, CSS, REST APIs, RxJS, Pinia and Git.
